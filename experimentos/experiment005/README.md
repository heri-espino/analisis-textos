# experiment005 — Ensambles y costo computacional

**Motivo:** evaluar si combinar modelos reduce errores y si la ganancia justifica el costo. **Método:** bagging de 20 regresiones logísticas con remuestreo de documentos vectorizados; votación dura de siete familias; stacking con las siete familias y XGBoost. Bases preespecificadas para evitar contaminación de validación externa; cinco pliegues externos comunes, cinco internos para generar OOF del stacking y búsqueda del metaestimador sobre el entrenamiento externo. Los modelos individuales se ajustan por GridSearchCV. El ranking de diez candidatos se congela antes de prueba; top tres, bootstrap y Holm. No se consulta prueba para escoger configuraciones. Los scores CV de individuales seleccionados pueden tener optimismo por búsqueda; las estimaciones externas de ensambles no son estrictamente equivalentes a CV anidada de todos los individuales.

**Reproducción:** python -m proyecto experiment005 (repite 003 y guarda 005). **Resultados:** resultados/experiment005/ y resultados/experiment003/ (ranking común, tiempos, predicciones, diversidad y comparaciones). **Siguiente paso:** analizar ganancia, estabilidad, diversidad y costo antes de concluir.

# experiment006 — Integración de descubrimiento temático y clasificación

**Pregunta:** ¿añadir pertenencia a grupos mejora la clasificación? **Diseño:** la misma representación léxica, más veinte indicadores one-hot (diez K-means, diez GMM diagonal EM), con SVD-50 y normalización L2 aprendidos solo en entrenamiento de cada pliegue. k=10 se motiva por el agrupamiento previo; no se transfieren sus asignaciones ni objetos ajustados. Aglomerativo y DBSCAN no tienen predict nativo. Se repiten los diez candidatos con idénticas rejillas, pliegues y protocolo de ensambles; Gradient Boosting conserva SVD léxico. Se contrastan diez diferencias pareadas de F1 con Holm y se informa el ranking global de veinte, además de los tres finalistas por CV como familia separada.

# experiment007 — Geometría textual en dos dimensiones

**Pregunta:** ¿qué estructura del corpus se conserva al proyectar a dos dimensiones? **Método:** TF-IDF del corpus completo, SVD-100 común; PCA centrado, ICA, t-SNE, UMAP, Isomap y Spectral Embedding. Todos reciben la misma matriz sin etiquetas. Se reutiliza el agrupamiento seleccionado de experiment002, alineado por huella. Dos dashboards 2×3 comparten exactamente las coordenadas y orden de documentos, cambiando únicamente el color. Se informa trustworthiness(15), tiempos de ajuste 2D, conectividad del grafo, parámetros y advertencias. Los tiempos no incluyen SVD ni la evaluación de vecindad. UMAP utiliza semilla fija y un hilo; se conserva el paralelismo compatible en otros estimadores.

**Reproducción:** con resultados de experiment002 disponibles, actualizar el entorno Conda y ejecutar `python -m proyecto experiment007` y `python -m proyecto entrega`. **Resultados:** resultados/experiment007 (CSV de coordenadas, métricas, metadatos JSON y dos PNG). **Límites:** exploración transductiva; no usar las proyecciones para clasificación ni elegir hiperparámetros a partir de las etiquetas. La geometría de cada método difiere, los ejes no son comparables y trustworthiness solo mide preservación local respecto a SVD-100.

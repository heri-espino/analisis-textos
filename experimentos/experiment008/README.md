# experiment008 — Diagnósticos complementarios para el informe
Se repiten las diez configuraciones K-means originales (dos representaciones, cinco k), registrando inercia y Silhouette coseno. Se reconstruye el árbol aglomerativo de enlace promedio sobre la matriz coseno del corpus de 3,300 textos y se conservan sus fusiones y cortes. Se registran los pesos medios TF-IDF de los doce términos de cada grupo original, alineado por huella. Se amplía el estudio SVD de regresión logística a 25, 50, 100, 200, 300, 400, 500, 750 y 1000 componentes, con los cinco pliegues originales, ajuste dentro de cada pipeline y sin consultar prueba. No se cambia la selección histórica de modelos ni se publica el corpus. El estudio dimensional adicional es exploratorio. Reproducción: python -m proyecto experiment008.

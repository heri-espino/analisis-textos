# experiment009 — Medoides y DBSCAN en el espacio original
Reconstruir TF-IDF y SVD-50 normalizada con semilla 42 y verificar identidad de la partición K-means de diez grupos mediante ARI=1. Ordenar los miembros de cada grupo por suma de distancias coseno a sus compañeros: el primero es el medoide, los otros dos son los siguientes candidatos (no una optimización k-medoides). Guardar identificador, categoría, distancia media, distancia al centroide y cinco términos distintivos por documento, sin texto original. Reajustar DBSCAN con la configuración seleccionada previamente sobre SVD-50 y verificar cobertura, silueta, ARI y NMI originales. Las etiquetas se unen por huella a las seis proyecciones sin modificar coordenadas. Reproducir: python -m proyecto experiment009. No reentrenar clasificadores: la prueba histórica se conserva.

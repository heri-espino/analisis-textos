# experiment010 — Corte jerárquico de diez grupos y pureza de ramas

Se reutiliza el enlace promedio calculado en SVD-50, con las hojas alineadas por huella con las particiones. Se fija k=10 para la comparación descriptiva con K-means. La opacidad de cada rama es la pureza de Gini normalizada por seis clases; el color indica su categoría mayoritaria. Las etiquetas no modifican el árbol. La silueta histórica del corte es 0.044101 y NMI 0.385975. Tamaños de los grupos (orden de primera aparición): 656, 1481, 53, 533, 28, 471, 20, 31, 26, 1. Se conserva la selección original de todos los modelos y sus evaluaciones. Reproducción: python experimentos/experiment010/reproducir.py. Los CSV generados se versionan en resultados/experiment010. El informe editorial utiliza la misma geometría t-SNE y no reajusta las proyecciones.
